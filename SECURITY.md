# Security

## Reporting a problem

Please report security problems privately, not in a public issue: on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which version and system you used. You'll get an answer within a few working days.

## What counts

Anything that lets a file, a web page, an update or another program make Convert Wheel do something the user didn't ask for: run code, read or send files, overwrite or delete them, or install an update that wasn't signed with the project's key.

Problems in the converters it runs (ffmpeg, ImageMagick, pandoc, LibreOffice, MuPDF) belong to those projects; tell us too if Convert Wheel makes one worse.

## Supported versions

Only the newest release gets fixes. From 0.1.1 the app offers new versions by itself; release notes say when a version fixes a security problem.
